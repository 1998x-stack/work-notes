# 分类体系

首页有三个互相独立的维度。

## 时间轴

date 为真实发生日期（YYYY-MM-DD）；多条记录同日可使用不同 slug。无明确日期时不能发明日期并公开，需要在输入阶段确认。每个卡片属于唯一日期与月份；周复盘 date 为周末/记录日之一，并在正文明确实际覆盖周期。前端支持月份、起止日期组合查询。

## 类型

meeting = 会议与讨论；daily = 当日工作脉络；weekly = 周度复盘；project = 专题/长期问题。类型指**记录形式**，不替代主题。

## 主题

product、engineering、collaboration、operations、research、management 是第一版固定主题。单条记录可属于 1—3 个主题；首页主题入口是交叉筛选，不强制互斥。主题是具体讨论内容，而不是员工部门或工作绩效。

修改 slug 时需考虑旧 URL、浏览器筛选参数和历史文章 metadata 的兼容；默认只追加新主题，不随意删除旧 slug。
